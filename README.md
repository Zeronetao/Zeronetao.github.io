# 陶倩的个人学术主页

本项目基于 [Academic Pages](https://github.com/academicpages/academicpages.github.io) 构建，使用 Jekyll 和 GitHub Pages 发布。

## 内容结构

- `_pages/about.md`：首页介绍
- `_pages/research.md`：研究方向与项目
- `_pages/publications.html`：论文列表
- `_pages/cv.md`：个人简历
- `_config.yml`：姓名、联系方式和站点地址
- `_data/navigation.yml`：顶部导航
- `_publications/`：每篇论文对应一个 Markdown 文件

## 发布

1. 按照 `PERSONALIZE.md` 补充可选信息。
2. 将仓库命名为 `Zeronetao.github.io`。
3. 推送到 GitHub 后，在 `Settings > Pages` 中选择 `GitHub Actions`。
4. 等待 `Build and Deploy Site` 工作流完成。

站点地址为 `https://zeronetao.github.io`。
